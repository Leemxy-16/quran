About This Project

A simple, clean Quran reading experience

☽ About Al-Quran Website

This is a simple, open-source Quran website built with pure HTML, CSS, and vanilla JavaScript. The goal is to provide a clean and respectful reading experience for the Noble Quran.

The site includes the full Arabic text of the Quran alongside English translations, a surah browser, and a keyword search tool.

📡 Data Source

All Quran content is fetched live from AlQuran.Cloud — a free, open-source RESTful Quran API maintained by the community.

The API provides Arabic text, multiple translations, transliterations, audio editions, and more. No API key is required.

API Base URL: https://api.alquran.cloud/v1/

📖 Translations Used

Muhammad Asad — A modern, scholarly translation known for its depth and insight.

Pickthall — One of the earliest and most respected English translations.

Sahih International — A widely used contemporary translation focused on accuracy.

🖋️ Fonts

Arabic text is rendered using the Amiri typeface — a classical Arabic font inspired by the renowned Bulaq Press style.

English headings use Cinzel, a font rooted in classical Roman inscriptions, chosen for its timeless elegance.

⚙️ Built With

Pure HTML5, CSS3, and vanilla JavaScript. No frameworks. No build tools. Just open the files in a browser.

The Fetch API is used to retrieve Quran data from AlQuran.Cloud on each page load.
